# 🛡️ منظومة متابعة وتصديق إجازات العاملين المدنيين - قيادة المنطقة العسكرية

منظومة إدارية ورقمية متكاملة مبنية باستخدام **Python & Django** ومجهزة للعمل كـ **تطبيق سطح مكتب محلي مستقل (Offline Desktop Application)** لإدارة ومتابعة وتصديق إجازات العاملين المدنيين داخل وحدة عسكرية، مع إحكام دورة التصديق والمراجعة الرقمية المعتمدة.

## 🎖️ فكرة ودورة عمل المنظومة

تمر دورة الإجازة العسكرية بثلاث مستويات إدارية متسلسلة لضمان الانضباط وتعيين البدلاء:

1. **العامل المدني**: يسجل دخوله، يختار اسمه من القائمة المنسدلة، فيظهر له تلقائياً مسمى وظيفته، قسمه، وحصر رصيد إجازاته المتبقية والمأخوذة وسجل إجازاته السابقة، ثم يملأ استمارة طلب الإجازة ويرسلها.
2. **مدير شئون العاملين**: يستقبل الطلب في فريم رسمي موضحاً به حصر رصيد العامل وتاريخه الإجازي، ومعه خياران: **(يصدق)** لإحالته للقيادة، أو **(لا يصدق)** مع إبداء الأسباب. كما يمتلك شاشات لمتابعة مصدقات اليوم، أرشيف الإجازات المعتمدة، إدارة وإضافة العاملين، واستمارة إجازة خاصة به.
3. **سيادة المدير العميد أ ح / ...**: قائد الوحدة ومدير المنطقة؛ يراجع الطلبات المحالة من شؤون العاملين، يطّلع على حصر الرصيد والتصديقات السابقة، وله السلطة النهائية في **(تصديق الطلب واعتماده)** مع توجيهات القائد أو **(رفض الطلب)**، ويصدر أمر إجازة عسكري معتمد رسمي قابل للطباعة بختم النسر وشعار الوحدة.

## ⚖️ قواعد وأنواع الإجازات وحساباتها

* **دورة سنة الإجازات**: تبدأ من **1 يوليو (شهر 7)** في السنة الحالية وحتى **30 يونيو (شهر 7)** في السنة التالية (مثال: `2026 / 2027`).
* **أنواع الإجازات الستة المقررة**:
  1. **اعتيادي**: متاح للعامل **30 يوماً** في السنة (يُخصم المستهلك ويُحسب المتبقي تلقائياً).
  2. **عارضة**: متاح للعامل **7 أيام** في السنة كحد أقصى.
  3. **إذن**: متاح **إذنان فقط** في السنة (يتم تسجيله بالساعات والتوقيت من/إلى).
  4. **مستشفى**: حصر أيام التواجد بالمستشفى بتقرير طبي.
  5. **مرضي**: حصر أيام الإجازات المرضية بقرار القومسيون الطبي.
  6. **مأمورية**: حصر أيام المأموريات الرسمية الميدانية للوحدة.

## 🔑 حسابات الدخول الرسمية الافتراضية

| الصلاحية / المستخدم | اسم المستخدم (Username) | كلمة المرور (Password) | الوظيفة والصلاحيات |
| :--- | :--- | :--- | :--- |
| **بوابة العامل المدني** | `مدنى` (أو `مدني`) | `مدنى` (أو `مدني`) | استعلام الرصيد، سجل الإجازات السابقة، وتقديم طلب إجازة جديد. |

| **مدير** | `مدير المنطقة` | `0000` | قائد الوحدة: الاعتماد النهائي أو الرفض، محرك بحث العاملين، حصر إجازات الوحدة، وطباعة الأوامر. |

## 🛠️ خطوات التثبيت والتشغيل لأول مرة

إذا تم تنزيل المشروع أو سحبه من المستودع لأول مرة، اتبع الخطوات التالية في موجه الأوامر (PowerShell أو CMD):

### 1. الانتقال لمجلد المشروع
```bash
cd "متابعة اجازات العاملين المدنيين"
```

### 2. إنشاء وتفعيل البيئة الافتراضية (موصى به)
```bash
python -m venv venv

# على نظام ويندوز:
venv\Scripts\activate
```

### 3. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 4. تطبيق ترحيل قواعد البيانات (Database Migrations)
```bash
python manage.py migrate
```

### 5. تهيئة الحسابات الرسمية والعمال المبدئيين تلقائياً
يقوم هذا الأمر بإنشاء حسابات المستخدمين الثلاثة، وإدراج عمال مدنيين تجريبيين في مختلف الورش، وتغذية المنظومة بإجازات تجريبية واقعية:
```bash
python manage.py init_military_system
```

## 🚀 طرق تشغيل المنظومة

### الطريقة الأولى: التشغيل كتطبيق سطح مكتب (Desktop Application) - (موصى بها محلياً)
تفتح المنظومة داخل **نافذة برنامج ويندوز مستقلة** بدون أشرطة متصفح، مثل أي برنامج ديسكتوب أصيل:
* **مباشرة بنقرة واحدة**: اضغط مرتين (Double Click) على الملف:
  ```text
  تشغيل المنظومة (برنامج ديسكتوب).bat
  ```
* **أو عبر سطر الأوامر**:
  ```bash
  python run_desktop.py
  ```

---

### الطريقة الثانية: التشغيل عبر المتصفح المحلي (Local Web Server)
* **بنقرة واحدة**: اضغط مرتين على الملف:
  ```text
  تشغيل المنظومة.bat
  ```
* **أو عبر سطر الأوامر**:
  ```bash
  python manage.py runserver 127.0.0.1:8000
  ```
ثم افتح متصفحك على الرابط:
👉 **`http://127.0.0.1:8000/`**

## 📖 دليل استخدام الواجهات الثلاث

### 1. واجهة العامل المدني (`/worker/`)
1. الدخول باسم `مدنى` وباسوورد `مدنى` (أو النقر على الكارت المخصص في شاشة الدخول).
2. اختيار اسم العامل من القائمة المنسدلة:
   * تظهر وظيفته وقسمه ورقم هاتفه ورقم بطاقته فوراً.
   * تظهر كروت الحصر اللحظي للرصيد المأخوذ والمتبقي لكل نوع إجازة.
   * يظهر جدول الإجازات السابقة وحالات التصديق عليها.
3. ملء استمارة الإجازة وتحديد التواريخ ثم الضغط على **"إرسال طلب الإجازة لمدير شؤون العاملين"**.

### 2. واجهة مدير شئون العاملين (`/hr/`)
1. الدخول باسم `مدير شئون العاملين` وباسوورد `1234`.
2. في شاشة **مستجدات طلبات الإجازة**:
   * فحص بيانات طلب العامل وفريم حصر رصيد إجازاته.
   * تدوين أي ملاحظات، ثم الضغط على **"يصدق (إرسال للعميد)"** أو **"لا يصدق"**.
3. متابعة الطلبات المصدقة لليوم من تبويب **"المصدقة اليوم"**.
4. الدخول على تبويب **"إدارة العاملين المدنيين"** لإضافة عمال جدد أو تعديل بياناتهم.
5. تقديم إجازة خاصة بمدير الإدارة باسمه ووظيفته الثابتين من تبويب **"إجازة مدير شئون العاملين"**.

### 3. واجهة سيادة المدير العميد أ ح / ... (`/commander/`)
1. الدخول باسم `مدير المنطقة` وباسوورد `0000`.
2. في شاشة **طلبات الإجازة للمراجعة والتصديق**:
   * الاطلاع على الطلب وتصديق مدير شؤون العاملين وملاحظاته ورصيد العامل.
   * الضغط على **"تصديق الطلب واعتماده"** أو **"رفض الطلب"** مع كتابة توجيهات القائد.
   * بمجرد التصديق، يمكن النقر على **"طباعة أمر إجازة عسكرية معتمد"** لإصدار نموذج A4 رسمي بختم النسر وتوقيعات القائد وشؤون العاملين ورئيس الورشة.
3. في شاشة **عرض إجازات العاملين ومحرك البحث**:
   * مشاهدة الحصر الإجمالي بالأعلى لكافة أنواع الإجازات المعتمدة بالوحدة.
   * البحث الفوري باسم أي عامل أو رقمه القومي للاطلاع على سجله وأرصدته فوراً.
4. في شاشة **بيانات القائد والصورة الشخصية**:
   * تحديث كلمة المرور، ورفع الصورة الشخصية الرسمية لسيادة العميد لتظهر بالترويسة وأوامر الإجازات.
